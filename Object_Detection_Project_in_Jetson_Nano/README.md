# YOLO를 활용한 횡단보도 보행자 보호 시스템

## 프로젝트 배경

교차로에서 우회전하는 차량 운전자의 부주의로 인해 횡단보도를 건너는 사람이 다치는 사고가 종종 발생함

## 프로젝트 목표

YOLO 객체 인식 알고리즘을 활용하여 횡단보도를 건너는 사람을 검출, 횡단보도에 사람이 검출되는 경우 우회전하는 차량에게 보여주면서 경고
## 프로젝트 검증 데이터

https://github.com/JinFree/deeplearningwithjetson

비디오 또는 카메라 입력을 화면에 보여주면서, 사람을 검출했을 때 화면에 적절한 방법으로 표시하는 프로그램
